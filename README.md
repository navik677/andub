# Anime GUI 🌸 (C++20 & GTK4)

Сучасний графічний застосунок (GUI) мовою **C++20** на базі фреймворку **GTK4** для пошуку, перегляду та завантаження аніме.
Цей форк є повною переробкою проєкту `anime-tui` у повноцінний нативний десктопний GUI з високою продуктивністю та мінімальним споживанням ресурсів.

---

## Особливості 🌟
- 🎨 **Сучасний інтерфейс GTK4:** красиві картки тайтлів із закругленими обкладинками високої якості, значками рейтингів та плавними анімаціями.
- 🚀 **Миттєвий асинхронний пошук:** живий пошук із затримкою вводу (debounce) без блокування інтерфейсу.
- 🔄 **Мультипровайдерність:** швидке перемикання між провайдерами (`АніЛібрія`, `AnimeVost`, тощо).
- 🖼️ **Розумне кешування постерів:** автоматичне завантаження та кешування обкладинок у `~/.cache/anime-gui/covers/`.
- 📺 **Стрімінг через mpv:** швидке відтворення HLS `.m3u8` з розширеним буфером, автоматичним підхопленням якості та заголовків.
- 💾 **Менеджер фонових завантажень:** завантаження серій через `yt-dlp` у фоні з діалогом прогресу та сповіщеннями робочого столу (`notify-send`).
- ❤️ **Улюблені та історія:** збереження улюблених аніме та відмітки переглянутих серій (`✓`).
- ⚡ **Без важких залежностей:** вбудований власний парсер JSON на C++20, підтримка як `libcurl`, так і системного `curl`.

## Вимоги та встановлення залежностей 🛠️

### Fedora Linux
```bash
sudo dnf install -y gcc-c++ meson ninja-build gtk4-devel libcurl-devel mpv yt-dlp
```

### Ubuntu / Debian
```bash
sudo apt update
sudo apt install -y g++ meson ninja-build libgtk-4-dev libcurl4-openssl-dev mpv yt-dlp
```

### Arch Linux
```bash
sudo pacman -S gcc meson ninja gtk4 curl mpv yt-dlp
```

## Збірка та запуск ⚡

У кореневій директорії виконайте скрипт збірки:
```bash
chmod +x build.sh
./build.sh
```

Або вручну через Meson:
```bash
meson setup build --buildtype=release
ninja -C build
```

Після успішної збірки запустіть додаток:
```bash
./build/anime-gui
```

## Структура проєкту 📁
```
src/
├── main.cpp                  # Точка входу застосунку
├── application.hpp/.cpp      # Ініціалізація GtkApplication та CSS теми
├── models/                   # Моделі даних (Anime, Episode, Stream, Quality)
├── utils/                    # JSON парсер на C++20, HTTP клієнт
├── providers/                # Реалізація провайдерів (Anilibria, AnimeVost, BaseProvider)
├── services/                 # Кеш зображень, запуск mpv, історія, улюблені, завантаження
└── ui/                       # Віджети GTK4 (Картка аніме, сторінка деталей, діалог завантажень, головне вікно)
resources/
└── style.css                 # Темна сучасна CSS-тема
```
